This plan is fixed before any new validation or test fit. Previous masking/official graph benchmark experiments are known. This is one separately identified measurement target. The released molecule and atom IDs, input hashes and split-assignment hashes will be checked on the server. Export aggregate counts and hashes only.

Use exactly the heavy-atom two-dimensional bond graph. Coordinates and stereo tags are omitted from every model feature. Use all measured carbons. Common features include the root atom descriptor (element, heavy degree, number of attached hydrogens including explicit H, formal charge, hybridization, aromaticity, ring membership), sums of the same descriptor at its heavy neighbors grouped by bond type (single, double, triple, aromatic, other), whole-molecule fractions by element, log(1+heavy-atom count), per-element counts of distinct atoms at exactly distance 2 and 3, and diagonal returns of orders 2 through 8 of the normalized untyped heavy-atom adjacency S. Element bins common to all are B,C,N,O,F,Si,P,S,Cl,Br,I,other. One-hot descriptor classes include an overflow/other bin; spectral fields are exactly five disjoint indicators: C, N, O, halogen (F/Cl/Br/I), and every remaining heavy element. The dichotomization is by atomic number and is independent of the shift labels.

The finite fitted-input layer is 15 appended channels: the 3rd, 5th and 7th diagonals for each of those five fields from ((S+Diag(p))/2) at each root (Spatial) or ((S+p_i I)/2) (Root-local). Common appends 15 zeros. Models have identical input/output width and parameter count. All arms observe the identical rich root, one-hop and molecular features. This is a fixed field on already attributed graphs. For a frozen-score reconstruction compute an independent marked-walk expansion separating edge steps S and pauses Diag(p) by number of pauses at each order; compare float32 inputs and predictions using the original frozen Spatial head. For a general mixture of distances, higher moments include several types of marked walks; the full expansion is what this check reconstructs.

Train on the H100 with five paired seeds 103,211,307,401,503. Standardize input coordinates by training mean/population SD (floor 1e−4, clip to [-10,10]), standardize shift using training means/SD, minimize mean absolute error using 128/128 ReLU MLP with dropout .1 at both hidden layers. AdamW LR .001, weight decay .0001, batch size 512. Use an independent paired generator for permutations and same model initialization/dropout RNG across arms. Each epoch evaluate official validation atom-weighted MAE, select earliest strict minimum, stop after 35 consecutive epochs without improvement or at 300. Reduce LR by factor .5 after ten unimproved validation epochs, floor .00003 (torch ReduceLROnPlateau, strict absolute threshold zero). No test-based selection. Freeze all 15 checkpoints before scoring the official test once. Report all checkpoint/stop epochs and validation curves.

Primary endpoint is mean across seeds of atom-weighted MAE across ALL measured test carbons, in ppm. Positive improvement is the control MAE minus the Spatial MAE. Require two-sided paired seed t95 (4 degrees of freedom) and paired whole-test-molecule percentile95 intervals for both Common−Spatial and Root-local−Spatial to have positive lower bounds.
