# Matched GINE test of the seventh return

Lock this plan before training the new GINE encoder or scoring its held-out roots. The prior atom MLP results on both collections are known. This is a follow-up on those same documented cohorts, not a newly held-out cohort. Train on ogbg-molhiv's official training molecules; select by AP on its official validation molecules. Score the original test and the previously fixed scaffold-disjoint PCBA test subset with no refitting or rescaling. Both outcomes are derived incidence of an OGB DOUBLE bond, scored only on carbon at exact graph distance three from the nearest heavy noncarbon. Neither official graph target is used. Edge types are removed from the encoder and from the neighbor features. Train/view all three arms together; freeze all 15 checkpoints before opening test scores.

Use three trainable GINE layers, width 64, trainable epsilon and a learned constant edge embedding for every bond. Initial node input is the shared element group (H, C, N, O, F, P, S, Cl, Br, I, other). Each layer sums ReLU(neighbor state + edge embedding), combines the sum with (1+epsilon) times the root state, and applies a two-linear-layer MLP with ReLU. The root readout concatenates the final state with the previous matched distance-study common inputs (size, degree, static returns through 8, composition, one-hop element counts, shared lower returns through six and 11 exact shell counts). One standardized slot carries zero, root-local seventh or spatial seventh. No other slot varies. Normalize using training roots only, clip continuous standardized inputs to [-10,10], fit a two-hidden-layer width-64 ReLU head and binary cross-entropy. The GINE and head train jointly. Precomputing recursive signatures of element and untyped neighbor multisets supports exact batched evaluation of identical per-layer node states; the signatures index sums for GINE and are never categorical predictor inputs. Test molecules can have new signatures. Validate the implementation against explicit graph propagation and gradients on a small graph. The target is atom-level; only the readout is allowed to use scalar seventh returns, preventing a changed input at another root from becoming a side channel.

Five paired seeds 103,211,307,401,503. Same architecture, initial weights, shuffled batches of 4096 training roots, optimizer AdamW (learning rate .001, weight decay .0001), no dropout or scheduler, first strict best validation AP checked every epoch; 100 epochs maximum, patience 15. Each comparison uses the same fixed schedule, with no endpoint or hyperparameter search. Report all arms, validation-selected epochs and per-seed results. One primary contrast per cohort is Spatial minus Root-local; Common is the prespecified extra control. Report mean AP and paired differences with 95% t intervals over training seeds conditional on the observed test cohort, and 1,000 matched whole-molecule bootstrap samples conditional on the five fits. A positive advantage over both controls on both collections requires the lower endpoints of all eight corresponding intervals to exceed zero. Analyze each cohort and contrast even when this joint criterion fails. Keep datasets, atom-level arrays and checkpoints on the H100.
