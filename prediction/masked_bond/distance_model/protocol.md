# Distance-matched atom annotation on the original OGB scaffold split

This protocol is closed before the new validation or test fits or their scores. The original molhiv scaffold split and earlier atom results are known. The target is a positive indicator that an atom touches a DOUBLE bond, with bond attributes hidden. This is a derived atom annotation, not the official molecular HIV activity endpoint.

The primary test is at d=3. The prespecified replication is d=2. In each setting train, validate and test exclusively on carbon atoms at exactly d bonds from the nearest heavy noncarbon atom. Use all qualifying carbons in each official split. Thus the ability to detect the presence of a heteroatom at d cannot by itself rank test roots in a stratum. A validation subset is never constructed using test data; no seed, target, assay or distance is selected by outcomes.

Define S=D^(-1/2) A D^(-1/2) with untyped unit edges, and field p=1 at noncarbon heavy atoms and zero otherwise. For each distance, both arms receive root/molecule size, root degree, static normalized returns 2--8, element identity and molecular element fractions, all eleven one-hop neighbor element counts, and both Local and Spatial normalized shifted diagonals through order 2d. The field is zero on the eligible root. This lower-order bank is identical on these roots by the distance bound. Use one copy of each coinciding lower order to avoid duplicate columns. The only differing input is the (2d+1)st return, of (S+p_i I)/2 or (S+Diag(p))/2 at i. The primary comparison uses these common inputs alone. The secondary prespecified sensitivity also supplies BOTH arms the vector of eleven unweighted element counts at exactly d, counting each distinct reached atom once regardless of path multiplicity. This tests whether a weighted arrangement contains information beyond shell composition. Keep the two sensitivity settings separate.

Fit the same width-64/64 ReLU atom MLP with standardized inputs, AdamW, unweighted binary cross-entropy, and 15-epoch schedule from the packaged revision14 atom experiment. Use five paired seeds 103,211,307,401,503 with shared initialization and batches. Scale each input by mean and population SD on its training stratum alone, SD floor 1e-4, clip to [-10,10]. Select by validation AP within that distance, retaining the earliest highest AP among all 15 epochs (check every epoch). Evaluate new test performance after all 40 trained checkpoints have been selected. Report mean test AP of the five fits, model differences, two-sided 95% paired seed t intervals with four degrees of freedom, and 1000 paired whole-test-molecule bootstrap replicates shared across models and seeds (seed 180421). A positive primary finding requires BOTH interval lower bounds above zero in the d=3 comparison. d=2 and shell-count sensitivities are descriptive. A second bootstrap draws chirality-aware Murcko scaffolds as intact clusters in each stratum using existing official molecule-to-SMILES mapping and seed 180422. Report test roots, positives, molecules, scaffolds, scaffold size concentration and sign counts. Distinct uncertainty units condition on the observed split or the frozen fits.

Without fitting labels, inspect all carbon roots whose open ball of radius d is free of heavy noncarbon atoms for d=1,2,3, including cases with none at exact radius d. Independently form Local/Spatial operator powers through order 8 in FP64. For each eligible root, verify equality of the diagonals through order 2d. At the first differing order test (Spatial minus Local) times 2^(2d+1) equals e=(S^d circ S^d)p; at the next order test difference times 2^(2d+2) equals e+u, where u=2(S^d circ S^(d+1))p and circ is entrywise multiplication. Verify zero unweighted-length-d exposure outside the exact-d shell and zero u on bipartite connected components; report observed error and support rather than treating a numerical tolerance as proof. With the trained spatial head frozen, evaluate the same score with the first differing input reconstructed as Local + e/2^(2d+1) under the same stored scaling, and report input residual, logit residual, and AP discrepancy. This deterministic reconstruction measures representation equivalence, not independent empirical accuracy. Exact direct and reconstructed features use the same precision interface as the network. Store benchmark data, per-atom labels/predictions and per-molecule mappings exclusively on the H100 server. Export captured protocols, code, and aggregate metrics only.
