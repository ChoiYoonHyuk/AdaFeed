# Frozen transfer of a distance-matched bond-annotation probe

This protocol is fixed before scoring any destination molecules with the source models or computing destination AP. The source molhiv distance results are known; PCBA is a prespecified external molecular collection. This transfer evaluates a derived atom annotation, not official PCBA assay activity. No destination assay labels are read. No destination validation, fitting, recalibration, threshold choice, feature choice or retraining is allowed.

Analyze only molecules in the original 43,793-molecule PCBA scaffold test split. Construct chirality-aware RDKit Bemis–Murcko scaffold strings for all 41,127 molhiv molecules, including the source validation/test splits, and all 43,793 destination candidates. Use the same parser and canonicalization for both collections, including the empty scaffold as an ordinary key. Attempt standard RDKit sanitization, then a documented non-strict valence fallback with all other sanitization steps. Exclude every destination molecule whose scaffold occurs anywhere in molhiv, and every destination whose scaffold cannot be assigned. An unresolved source scaffold or overlap remaining after filtering invalidates the disjointness audit. Report population and excluded molecules/scaffolds explicitly. Do not adjust the exclusion rule after seeing coverage or outcomes.

Keep all carbon roots at exact unweighted distance d from the nearest heavy noncarbon atom on retained molecules. Use d=3 with the eleven exact-shell element counts in BOTH Local and Spatial as the primary test. d=3 without shell counts and d=2 with and without them are descriptive sensitivities. The target is touching an OGB raw DOUBLE bond. All bonds have weight one, and their types are hidden from features. Compare two independent constructions of each eligibility mask and double-bond target. Verify the feature vectors and frozen head predictions against the archived source pipeline on predetermined molhiv test molecules before scoring PCBA. Use the 40 existing five-seed source checkpoints, five paired seeds 103, 211, 307, 401 and 503, with their stored training-stratum means/SDs; freeze the existing learned network, rounding, clipping and input schema. SHA-256 of the source checkpoint container a9e83a1c236baa0bd5d1290b4e78c59af0c3b23397fd444a8448bbe30ee7311d. No PCBA training, head or molecular fingerprint from the native graph task enters this evaluation.

Report AP of each arm, difference of mean single-seed AP, individual paired seed differences, positive seeds, two-sided t95 over five paired seeds, and 1,000 paired whole-molecule bootstrap draws (seed 180523, resampling eligible molecules and pairing arms and seeds). Report counts of roots, positives, eligible molecules, effective scaffold clusters and maximum cluster fractions. A second 1,000 paired intact-scaffold bootstrap (seed 180524) assesses dependence among retained test molecules. Primary positive transfer requires both paired-seed and molecule-bootstrap lower bounds above zero; the scaffold interval and all sensitivities are always reported. If label/feature alignment or scaffold audit fails, report the failure before performance and do not loosen criteria. Only scripts, protocol and non-identifying aggregates leave the H100.
