# Rooted four-cycle counts on the I²-GNN benchmark

Use the original GraphPKU/I2GNN counting benchmark, release commit f514487625b42406dcd85ca55ac66436606f9aac, data/count_cycle/raw/data.mat (SHA-256 758ae12bd05ced3c1ba609d81f0d0dbdc1d227d486e3f2c1c517b47fe7dad9b4). The official run_count.sh identifies zero-based target 1 as four-cycle counting. Use the provided graph-wise train, validation and test indices without modification, respectively 1500, 1000 and 2500 graphs. The endpoint is the native count of unoriented simple cycles of length four containing a given root, allowing chords. We selected this endpoint from its algebraic relation to a cubic change before reading validation or test labels. The target index and orientation were checked on the first three training graphs using the number of unordered pairs of common neighbors between the root and a distinct opposite vertex.

For simple binary adjacency A, choose the degree field p=d from the unshifted two-step returns. Use the same rooted static features 1, d, d², d³, diag(A³) and diag(A⁴) for both arms. Give one additional scalar h to each arm. Root-local uses the cubic at root i from A+d_i I; Spatial uses the cubic from A+Diag(d). Fit one unregularized least-squares linear head per arm in float64 on all training roots, with a deterministic minimum-norm solution at relative singular-value cutoff 1e-12. No validation or test labels select covariates, coefficients, targets, settings or checkpoints. Record raw root MAE and MAE divided by the training+validation node-label standard deviation as in the released benchmark. Include all official splits. The paired test improvement is Root-local MAE minus Spatial MAE. Estimate a 95% percentile interval with 2000 resamples of the 2500 test graphs with replacement (seed 2901), weighting roots as in the unresampled MAE. This interval describes held-out graph composition for fixed trained heads.

Separately evaluate the exact formula 2 c_i = (A⁴)_ii - 2d_i² + d_i - (h_i_spatial - h_i_local) against the distributed labels directly. For the control supplying the sum of neighbor degrees, replace the cubic difference by sum_{j~i} d_j - d_i². Record root MAE for the direct identities and for the algebraic expression omitting the cubic difference. Sum the latter expression over roots and divide by four to check graph totals against the sums of distributed root labels divided by four. Pool the cubic difference both uniformly and with degree weights, checking the zero sum and the negative edge energy on each graph. These graph-level checks are algebraic consequences, while the benchmark endpoint itself is at node level.

For each selected finite input bank, group held-out roots by equality of the entire integer feature tuple. Report the number of groups containing multiple target values, how many roots they contain, and the minimum MAE attainable by any deterministic readout on those tuples, computed via within-group test-label medians. The median quantity uses test labels only for a sample lower bound and is not an out-of-sample model. Distinguish this finite-bank statement from a comparison to complete static return profiles. Controls and graph reductions use no new graph labels; neither graphs nor individual predictions are included with the aggregate report.
