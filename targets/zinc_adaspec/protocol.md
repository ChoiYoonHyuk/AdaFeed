# AdaSpec loop-weighted graph readout on ZINC

This comparison fixes the prediction target, arms, training schedule and evaluation rule before fitting. The official ZINC-12k graph-regression split has 10,000 training, 1,000 validation, and 1,000 test molecules. The sole predictive metric is mean absolute error (MAE) on the official target. Use all molecules on each split, the provided atom type as a one-hot feature, and the same undirected unweighted chemical bonds in every arm.

## Model and controls

Use the released AdaSpec small GPRGNN class and its ten-step GPR propagation (commit d76aa64d3075a73b014345548473d672f103045a). We adapt its node outputs to inductive graph regression by summing 16 propagated node channels and appending one scalar cubic return to a shared 64-unit ReLU prediction head. The node MLP has 64 hidden units, zero dropout, and a learnable ten-step PPR-initialized filter (alpha 0.1). All predictive parameters train jointly. Use the fixed degree-dependent bias b_i=d_i/(1+d_i) from the preceding cut-pair forward study to define loop weights on unseen molecules. Use the published matrix rule with adjacency coefficient 1, identity coefficient 0.1, and feature-dependent edge coefficient 0.01. For the resulting matrix M, p_i=M_ii and S=M-Diag(p). Thus the Spatial cube is the third power of the SAME matrix that propagates node outputs. The effective diagonal p is also the weight for graph pooling. Loop values are fixed throughout fitting. An unconstrained per-vertex parameter in a transductive node classifier has no specified value on a new molecule.

For each molecule compare cubic returns r_i=((S+p_i I)^3)_ii (Root-local) and r_i=(M^3)_ii (Spatial). Pool either as sum_i r_i or as sum_i p_i r_i. The two uniform arms have exactly the same scalar by the cubic identity and share the same training run, after a direct FP64 equality check. The three distinct scalars are standardized separately with training-only mean and standard deviation. Each head has identical capacity; the common propagated channels are summed and divided by 16 in all arms. We check the weighted difference against the edge formula and record the fraction of molecules with nonzero energy.

## Optimization and evaluation

Seeds 103, 211, 307, 401 and 503 are paired across arms, with identical initial parameters and minibatch order. Adam (learning rate 0.001, zero weight decay), batch size 256, MAE loss, at most 160 epochs, patience 25 epochs after the best validation MAE, no warmup or scheduling. Strictly smaller validation MAE selects a checkpoint; ties keep the earliest. Test predictions are computed after training and checkpoint selection for all 15 fits. The two primary comparisons subtract loop-weighted Spatial MAE from (i) loop-weighted Root-local MAE and (ii) uniform MAE. Report each seed, the mean paired improvement, a two-sided 95% t interval over matched fits, and separately a percentile interval from 2,000 molecule resamples with replacement (seed 731), with seed-averaged paired losses. Report a predictive advantage over both controls only when the lower limits of both intervals are positive for each comparison. These intervals condition on the chosen official split. Data, model outputs per molecule and checkpoints remain on the compute server.
